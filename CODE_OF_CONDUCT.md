# Code of Conduct

Squintless is a small accessibility-focused project. Keep participation respectful, practical, and welcoming.

## Expected Behavior

- Be kind and professional.
- Assume good intent.
- Give feedback that is specific and actionable.
- Respect different levels of experience.
- Keep accessibility and readability discussions grounded in users' needs.

## Unacceptable Behavior

- Harassment, intimidation, or personal attacks.
- Dismissive comments about age, disability, vision, or assistive needs.
- Trolling, insults, or sustained off-topic disruption.
- Publishing private information without permission.

## Enforcement

Maintainers may remove comments, close issues, reject contributions, or block participants who violate this code of conduct.

Report concerns privately to the project maintainers when possible. If a private contact is not available, open a GitHub issue with only the information that can be shared publicly.
