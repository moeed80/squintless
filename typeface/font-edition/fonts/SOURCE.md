# Red Hat Display Black Source

The Font Edition uses the official Red Hat Display variable font from the Google Fonts repository:

- Repository: `https://github.com/google/fonts`
- Directory: `ofl/redhatdisplay`
- Font file: `RedHatDisplay[wght].ttf`
- Local copy: `RedHatDisplay-wght.ttf`
- Weight axis used by the asset generator: `wght=900`

Google Fonts lists `wght` from `300` to `900`; `900` is the Black instance used for this experiment.
