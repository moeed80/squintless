# Security Policy

Squintless is a Pebble watchface with no network service, server component, account system, or data storage.

## Supported Versions

Security updates are handled for the latest public release.

## Reporting a Vulnerability

If you find a security issue, please avoid posting exploit details publicly before maintainers have a chance to review it.

Use GitHub's private vulnerability reporting tools if available. If private reporting is not available, open a GitHub issue with a minimal description and ask maintainers how to share details privately.

## Scope

Relevant reports include issues that could affect Pebble device stability, build integrity, dependency safety, or distribution artifacts.
