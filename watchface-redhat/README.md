# Squintless Red Hat Edition

Experimental Pebble Time 2 watchface variant using Red Hat Display Black numerals.

This build exists for readability comparison against:

- `watchface/`: Squintless SVG Edition
- `watchface-russo/`: Squintless Russo Edition

The layout, battery indicator, update logic, and Emery target match the other editions. Only the numeral source changes.

## Build

```sh
pebble build
```
